## Phase 1: Core Hash Field

**Purpose**: Coordinate rotation, two hash functions, anisotropy blend, threshold/softness. No drift, no processor mode yet.

- [x] T003 Write codebox — coordinate rotation: `along`/`across` from `norm` rotated by `angle` (theta = angle * PI/180)
- [x] T004 Write codebox — sin-based hash on `along` axis: `h_parallel = sin(along * freq * 43758.5453); h_parallel = h_parallel - floor(h_parallel)`
- [x] T005 Write codebox — arithmetic hash combining both axes: `h_iso = sin((along * 127.1 + across * 311.7) * freq); h_iso = h_iso - floor(h_iso)`
- [x] T006 Write codebox — anisotropy blend: `hash_field = mix(h_iso, h_parallel, anisotropy)`
- [x] T007 Write codebox — threshold/softness: `stipple = smoothstep(threshold - softness * 0.5, threshold + softness * 0.5, hash_field)`
- [x] T008 Write codebox — source mode output: `out1 = vec(stipple, stipple, stipple, 1.0)` with bypass (`mix(out, vec(0,0,0,1), bypass)`)
